COMO USAR:
1. Extraia o arquivo "NeitanOtimizador.exe" para qualquer pasta (ou Área de Trabalho).
2. Dê dois cliques em "NeitanOtimizador.exe".
3. Confirme a permissão de Administrador (necessária para aplicar ajustes de
   energia, serviços, rede e limpeza profunda do Windows).
4. Se o Windows exibir a tela azul do SmartScreen ("O Windows protegeu o computador"),
   clique em "Mais informações" e depois em "Executar assim mesmo".
