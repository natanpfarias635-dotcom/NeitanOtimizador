**NeitanOtimizador PRO** é uma suite completa de otimização de sistema, redução de latência (Input Lag / Ping) e limpeza avançada para Windows 10 e 11, desenvolvida com interface moderna **Crimson Obsidian (Vermelho & Preto)**.

---

## 📥 Download Direto (Sem precisar instalar Python)

Para baixar e usar imediatamente:
1. Acesse a aba **[Releases](../../releases)** aqui no GitHub (ou a pasta `Release_Para_Amigos`).
2. Baixe o pacote **`NeitanOtimizador_PRO_v2.0.zip`**.
3. Extraia e execute **`NeitanOtimizador.exe`** (ele já solicita privilégios de Administrador automaticamente).

---

## 🛠️ Funcionalidades Principais

| Módulo | O que faz |
| :--- | :--- |
| **⚡ Otimizar em 1 Clique** | Limpa caches/shaders, libera Memória RAM (`EmptyWorkingSet`) e aplica o perfil *Gamer Competitivo*. |
| **📊 Painel em Tempo Real** | Monitora CPU, RAM, Disco, Processos, Uptime e Índice de Saúde (0 a 100). |
| **🎯 5 Perfis de Performance** | *Gamer Competitivo*, *Gamer + Streamer*, *Trabalho & Produtividade*, *Notebook* e *Neitan Ultra Red*. |
| **🧹 Limpeza Profunda** | Temporários, Cache de Navegadores, Shaders (DirectX/NVIDIA/AMD), Scanner de Arquivos Grandes e Duplicados (`SHA-256`). |
| **🚀 Otimizações de Sistema** | Mouse Raw 1:1, Desativar FSO, Menu Delay Zero, Gerenciador de Serviços, Plano **Ultimate Performance** e Inicialização. |
| **🎮 Jogos & Game Boost** | HAGS, Prioridade MMCSS (`SystemResponsiveness=0`), Auto Game Mode, Game Boost de Sessão e Detector de Bibliotecas. |
| **🌐 Rede & Ping Gamer** | Benchmark de DNS ao vivo, Teste de Jitter/Perda, DNS Cloudflare/Google, Liberação QoS e Reset Winsock/TCP-IP. |
| **🛡️ Privacidade & Telemetria** | Bloqueio em lote de Telemetria, ID de Anúncio, Bing no Menu Iniciar, Widgets e Xbox Game DVR. |
| **📜 Histórico & Restauração** | Criação de Ponto de Restauração oficial do Windows e reversão de sessões em 1 clique. |
